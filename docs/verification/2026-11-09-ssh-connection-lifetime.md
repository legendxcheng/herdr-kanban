# SSH 连接生命周期与 reset 恢复（#49）

日期：2026-11-09。规格：https://github.com/legendxcheng/herdr-kanban/issues/49 。

## 实现

- 远端原生客户端首次访问后保留到 Kanban 退出，不受原 60 秒空闲回收和 3 组容量限制；本机仍沿用原资源策略。任务选择、生命周期取消与机器连接分离，完成任务不会使其他同机对话重新握手。
- 引用索引及列表、状态、Git、目标观察使用共用的应用级只读池实现，各用途独立通道。缓存 TTL 不决定连接寿命；身份/helper 改变、停用或退出时取消并释放对应资源。写操作继续走操作专用通道，不进入共享只读队列。
- `view_identity` 在远端完成原有目标→Codex 会话→目标核验，通过保留的只读通道返回，打开时移除重复搜索校验；本地授权、执行代次、只读权限和输入隔离继续生效。
- 当前任务与 Workspace 普通终端均按 2/5/10/30/60 秒有界重连，成功重置预算，耗尽保留人工重试。普通终端自动重连携带可选 `reconnect`，只取已保存目标；不创建替代 shell，不重发提示词、Enter、按键或启动请求。
- 半帧、EOF 和管道 I/O 错误统一为连接错误，身份/格式错误独立保留。响应结构检查在连接槽内完成，坏连接被丢弃，下一次消费者可重建。
- 连接检查有取消代次及原子发布边界，停用或退出不接受迟到启用；连接/停用转换统一排序，SSH 安装不持有转换锁或数据库锁。原生会话在池锁外停止及写日志。
- `terminal/connection-events.jsonl` 记录授权、创建、复用、就绪及关闭原因，限制大小并保留一份轮转文件，不记录业务输入和认证信息。无数据库迁移。

## 真实桌面与 SSH

使用独立 SQLite、WebView2 数据目录、专用远端 Workspace 及两个仅回复测试标记的 Codex 对话。应用是当前共享工作区的 debug/custom-protocol 构建，不替换用户运行中的安装版。故障注入仅终止该隔离应用的 SSH 子进程。

| 场景 | 结果 |
| --- | --- |
| 同机 A/B/A 连续切换 | 复用同一 SSH 桥接与 WezTerm PID；四次样本含画面稳定等待为 1312/1280/1328/1469 ms |
| 输入隔离 | 专用 pane 写入未提交标记，另一 pane 不出现，切回原 pane 可见，随后清除；未按 Enter |
| 切到 Todo 后空闲超过 95 秒再返回 | 原 SSH 和查看进程仍在，返回复用；草稿离开确认需显式处理，因此不以此轮墙钟时间宣称热切换延迟 |
| 查看桥接 reset | 自动创建新桥接并恢复原任务；目标绑定不变 |
| 只读查询连接 reset | 原对话自动恢复；半帧分类另由传输回归覆盖 |
| 普通终端桥接 reset | 自动恢复原保存 shell，target JSON 不变 |
| 业务重复执行 | 两个任务原绑定不变，dispatch 记录数不增加 |
| 检查连接期间停用 | 未完成检查返回 `machine.cancelled`，数据库保持 disabled，桥接及只读子进程已释放 |
| 正常关闭主窗口 | 在持有活动连接时关闭真正的 Tauri 主窗口，约 0.52 秒退出，所记录 SSH/查看子进程全部结束 |

退出后另以真实 SSH 确认两个测试 Agent 仍存在，再核对唯一 ID 与测试名称，关闭本次专用 Workspace 并确认列表中已不存在；没有关闭用户业务 Workspace。对应记录为 `agents-survived-exit.json` 和 `cleanup.json`。

验收脚本修正了定位状态先于画面、读日志末行尚未写完、Todo 草稿离开确认及需只关闭主窗口等测试同步问题。此前失败运行不计为产品验收通过；上述结果取自后续分段实测及原始进程/绑定断言。证据位于 `.scratch/issue49/` 的 `live-results.json`、`live-final.log`、`live-tail.log`、`exit.log` 和隔离应用连接阶段日志。

## 交付边界

仅一台真实远端 devpc；四台电脑覆盖来自四个独立机器身份的自动化测试，不能称为四台真实电脑验收。未执行数小时弱网、跨屏 DPI、安装升级或另一台电脑反向连接验收。连接复用仍需实时授权及定位，不承诺无网络等待。

共享工作区还包含既有同步性能、Codex 发现、其他修复及并发归档任务。提交按本次开始前快照隔离；用户明确允许纳入尚未提交的只读连接池与测试，并带上必要模块/路由注册。共享工作区的全量和桌面证据不自动等于独立提交快照的全部运行证据；独立快照另行做编译、类型和针对性回归检查。
