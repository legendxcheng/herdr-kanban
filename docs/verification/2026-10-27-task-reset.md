# 异常任务查看提示词与退回 Todo 验收

日期：2026-10-27。用户确认方案后实施；没有修改用户实际失败卡片，没有自动重试旧派发。

## 最终行为

- 开发中、失败、准备中和待核实卡片提供“查看提示词”，以只读表单展示已保存正文、引用与图片；可选择文字复制，不提供保存或派发。
- 失败或待核实任务提供“退回 Todo”。应用内确认默认聚焦取消，明确旧 Agent 可能仍运行，不关闭它、不撤销文件修改。pending 启动／派发不允许重置。
- 保留同一 task ID、项目、创建时间、标题、正文、图片、优先级及模型设置；成功后打开右侧 Todo 编辑面板。下一次手动启动使用新会话。
- 普通看板和汇总看板共用流程，先处理已有 Todo 草稿。取消不写入，重复提交幂等，确认依据过期时拒绝；刷新失败仍展示重置返回的最新任务。

## 数据及并发边界

schema 16 增加执行代次和两张重置／目标隔离表。事务保存旧状态、派发摘要、会话与目录快照，将旧生命周期、派发及图片派发记录关联到唯一的 `retired:<request UUID>` 历史作用域，再清理当前执行关联并递增代次。原任务通过 `task_execution_resets.task_id` 关联历史；原 operation ID、状态、错误、正文及图片引用保留，不把 unknown 伪装成未发送。

生命周期写入复核操作归属；派发准备、图片上传和手动绑定另核对执行代次。旧 worker 的迟到会话、发送结果、完成清理和错误不能污染下一轮。已知旧 terminal 按 machine/session/terminal 隔离；未知创建继续保留创建前清单，后来明确创建的 terminal 可凭独立创建证据使用。普通“移回未开发”原有保留会话语义不变。

重置仅调用本地数据库及本应用查看连接清理，不查询／关闭 Herdr 进程。在途外部命令仍可能完成，已发生的代码修改不会回滚。历史和目标隔离不会随原任务删除而清除；隔离目前不提供解除入口。
