# 远端提示与任务切换长连接验收

日期：2026-10-26。范围：远端 Prompt `@` / `$` 候选加速，以及用户追加确认的 Herdr 任务切换复用。

## 实现

- 编辑器打开时预热远端文件/技能完整索引，按电脑、session、主机身份、项目及目录范围隔离。30 秒缓存，显式刷新立即重扫；不会将前 50/30 条展示结果当作完整索引。
- 查询通过持久 SSH 连接运行本版本 helper 的只读帧协议。每次检查请求 ID 和主机身份，错误后丢弃连接；下一次重试建立新连接。目标校验与索引扫描分开连接。
- 原生客户端按电脑/session 复用，切任务重新验证进程和绑定，再发送客户端范围的 pane.zoom。每次选择拥有新代次，过时选择和回执不再显示旧窗口；切换期间阻断输入，恢复后按最新焦点快照检查 pane 输入。
- 返回仍聚焦原 pane 的保留窗口时，Herdr 的幂等 zoom 可能只返回回执。使用最近快照加本次新回执确认，避免等待不会出现的重复快照。保留原生菜单与主动导航能力。
- 原生客户端最多保留 3 个，空闲 60 秒回收；只读连接最多 8 条，空闲 60 秒由巡检回收。退出清理查看客户端，不关闭业务 Herdr server/Agent。不自动重发 Prompt。

## 环境与隔离

Windows Tauri/WebView2、Herdr 0.9.5、WezTerm，真实 SSH 连接远端 Windows 电脑。使用独立 SQLite、WebView2 配置和本地验收 session；远端另建 `kanban-acceptance-persistent-*` workspace，两个空闲 Codex 测试 pane。用户业务数据库仅作只读连接信息来源，未向业务任务发送输入。

原版性能对照使用已安装 Kanban 二进制，但另起独立数据目录和调试实例；新版运行当前源码 debug 构建。测量为单次环境的少量样本，不代表所有网络或项目的保证。
