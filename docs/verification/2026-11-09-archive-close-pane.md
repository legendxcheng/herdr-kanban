# 归档关闭 Pane 验证

日期：2026-11-09。用户授权单个归档和批量归档同时关闭任务 Pane。使用共享工作区开发，保留此前及并行发生的其他修改；没有安装或替换用户正在运行的 Kanban。

## 实现

- `commands::archive_task/archive_completed_tasks` 使用后台 Workflow 归档服务，接口参数保持不变。
- `task_archive.rs` 在事务中检查 done、归档状态及批量项目范围，然后取得 complete 生命周期占用；不会把并发启动后的任务误当作待归档任务关闭。
- 有绑定时在所属电脑核验精确目标和 Codex 会话，调用现有关闭流程并确认 Pane 消失。归档、绑定释放和 complete 成功在同一事务提交；无绑定时可直接本地归档，无需远端在线。
- 身份变化、会话缺失、断线、关闭未知或归档写库失败保留卡片及绑定。显式重试先检查 Pane 是否已消失，已消失不重发关闭；未知启动、未决派发及 pending 生命周期仍阻止归档。
- 批量继续处理后续 ID，分别返回成功、跳过和失败。单项归档显示关闭中的状态，失败后刷新卡片；会话、正文和操作记录保留。删除行为不变，无数据库迁移。

## 真实桌面与 Herdr

使用独立 SQLite、WebView2 用户目录、专用 Workspace 和测试 Codex 任务，真实 Tauri IPC 与 Herdr，不使用模拟 IPC。为覆盖“已完成但 Pane 仍在”，测试只在隔离数据库中把刚启动任务标为 done，保留原绑定；身份失败样本只替换隔离绑定中的进程身份。普通完成本来就会关闭 Pane，因此这些是显式准备的历史残留/身份失败夹具，不代表正常完成必然遗留窗口。

本机与 SSH devpc 均已通过：

1. 点击任务卡片归档，确认卡片消失、原 Pane 消失、原进程退出，保留会话及原完成日期，不新增派发。
2. 点击“一键归档”，两项中正常项关闭并归档，身份不匹配项保留，界面显示成功 1 / 失败 1。
3. 校正测试绑定后，点击归档成功重试；进行中的第三方测试任务始终保留。
4. 最后正常点击该保留任务的“完成”，确认既有完成路径正常。
