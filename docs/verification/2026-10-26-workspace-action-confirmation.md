# Workspace 隐藏与删除二次确认

日期：2026-10-26。

## 实现

- 侧栏隐藏和删除统一使用 `WorkspaceActionDialog`，显示电脑及 Workspace 名称，确认前不调用隐藏或删除接口。
- 隐藏说明保留任务及 Herdr Workspace，可从添加入口恢复；删除说明本地项目及全部任务删除不可撤销，Herdr Workspace 保留。
- 默认聚焦取消，Tab 循环，取消按钮、Esc 和遮罩均退出并恢复触发按钮焦点。背景 inert，复用原生终端的弹窗可见性检测。
- 确认后同步卸载弹窗，再执行操作；隐藏当前项目时继续原有未保存修改保护，两个弹窗不重叠。同步引用和禁用按钮阻止重复操作，失败通知后可以重新确认。
- 本次只改前端，无新增 IPC 或数据库迁移。

- Windows Tauri/WebView2：鼠标悬停侧栏显示按钮后打开两类弹窗，默认取消获得焦点；分别用取消按钮、Esc、遮罩关闭，确认两张任务及原项目保留。
- 真实 Herdr/WezTerm：每次弹窗打开后检查原生窗口隐藏，取消后检查恢复显示；查看连接不因取消而删除任务或关闭 Agent。

- 重新添加后确认删除：查询 SQLite 确认本地项目及全部任务已移除，同时通过真实 Herdr CLI 确认外部 Workspace 仍存在。
